Ovomium @MOD_VERSION@ - des améliorations pour Lonely Mountains: Downhill
========================================================================

Pour Lonely Mountains: Downhill 1.6 sur Steam (Windows ; Linux et Steam Deck aussi) :
- jouer à plusieurs en réseau local : vous voyez les autres joueurs rouler sur votre
  piste, et vous pouvez lancer des courses ensemble ;
- vue à la première personne ;
- démarrage direct au menu, clavier AZERTY reconnu tout seul.


INSTALLER
---------
1. Clic droit sur le fichier .zip → « Extraire tout… » → Extraire.
2. Dans le dossier extrait, double-cliquez sur « Installer Ovomium ».
3. Windows demande une autorisation (pare-feu) : cliquez « Oui ».
4. Un message confirme l'installation. C'est tout.

Si Windows affiche « Windows a protégé votre ordinateur » :
cliquez « Informations complémentaires » puis « Exécuter quand même ».
(Le mod n'est pas signé par un éditeur connu, c'est normal.)

PREMIER LANCEMENT : LONG (2 à 10 minutes)
Une fenêtre noire (MelonLoader) prépare le jeu. C'est normal : ne fermez rien,
le jeu s'ouvre ensuite. Les lancements suivants sont rapides.


JOUER
-----
Tous les joueurs doivent être sur le même réseau (même box / même Wi-Fi) et avoir
la même version d'Ovomium. Les autres apparaissent tout seuls.

  F1                  lancer une course sur votre piste, ou accepter une invitation
  F1 maintenu 1,5 s   abandonner la course (ou l'annuler si vous l'avez lancée)
  F2                  changer l'aspect des autres joueurs (normal / transparent / teinté)
  F3                  afficher / cacher la liste des joueurs
  V                   vue à la première personne / vue normale (manette : clic du stick droit)
  Manette : Select (Affichage) maintenu + A = comme F1 ; Select + B maintenus = abandonner
            (appuyez sur Select AVANT A ou B)

Une invitation sans réponse est refusée au bout de 15 secondes.


DÉMARRAGE RAPIDE ET CLAVIER
---------------------------
- Au lancement, les logos et l'écran « Appuyez sur… » sont passés : le jeu arrive
  directement au menu (environ 10 secondes de gagnées). Pour les revoir : dans
  <dossier du jeu>\UserData\Ovomium.cfg (Bloc-notes, jeu fermé), SkipIntro = false
- Clavier AZERTY (ou QWERTZ…) : les touches lettres du jeu suivent votre clavier
  toutes seules. En AZERTY : Z Q S D pour rouler et diriger (au lieu de W A S D),
  comme dans les menus. Les flèches marchent toujours. Si la détection se trompe :
  KeyboardLayout = "azerty" (ou "qwertz", "qwerty" = touches d'origine du jeu)
  dans Ovomium.cfg. Les touches F1 à F4, V et 1/2/3 sont les mêmes partout.
- Changer les touches d'Ovomium : RaceKey, StyleKey, PanelKey, EchoKey, CameraKey
  dans Ovomium.cfg (noms des touches d'Unity : F1…F12, V, Keypad1…).


VUE À LA PREMIÈRE PERSONNE (mod LMD-Camera)
-------------------------------------------
En piste : touche V, ou clic du stick droit (R3) à la manette, pour passer de la
vue normale à la vue à la première personne, et inversement. Ce choix est mémorisé.

Touches du mod lui-même : 1 = première personne, 2 = vue normale,
3 = troisième personne.

Réglages (jeu fermé, avec le Bloc-notes) : <dossier du jeu>\UserData\LMD-Camera.cfg
par exemple FP_FOV (champ de vision), FP_HideBike (cacher votre propre vélo), etc.

Pour ne pas l'utiliser : supprimez <dossier du jeu>\Mods\LMD-Camera.dll.

LMD-Camera par flo-st, licence MIT (fichiers\LMD-Camera-LICENSE.txt),
https://github.com/flo-st/LMD-Camera


RÉALITÉ VIRTUELLE (mod LMD-VR, à installer à part)
--------------------------------------------------
Ovomium fonctionne à côté du mod LMD-VR (casque OpenXR, Windows) :
https://github.com/visual-gh/LMD-VR (installation : voir sa page).
- LMD-VR prend F5, F6, F7, F9, F10, F11 : les touches d'Ovomium (F1 à F4, V)
  ne les croisent pas. Si vous les avez changées et que l'une tombe sur LMD-VR,
  un message le signale au menu.
- Pendant la VR, V et R3 d'Ovomium sont coupés : la vue se change avec LMD-VR
  (F5, ou LB + RB + croix).
- Le panneau des joueurs, les messages et l'affichage des courses ne sont pas
  visibles dans le casque, sauf avec la caméra « Screen » de LMD-VR.
- LMD-VR est récent et n'a pas encore été testé avec Ovomium dans un vrai casque.


ÇA NE MARCHE PAS ?
------------------
- Personne n'apparaît :
  * Vérifiez que tout le monde a lancé l'installeur et le même Ovomium (F3 le dit).
  * Pare-feu : relancez « Installer Ovomium » et répondez « Oui » à Windows.
    Si Windows demande d'autoriser le jeu sur le réseau : cochez « Réseaux privés »,
    puis « Autoriser l'accès ».
  * Votre réseau doit être « Privé » : Paramètres → Réseau et Internet → votre
    connexion → Type de profil réseau : Privé. (L'installeur le propose.)
  * Certaines box ou Wi-Fi « invités » isolent les appareils : essayez un autre réseau.
- Joueurs sur des réseaux différents (ex. via Tailscale) : ouvrez
  <dossier du jeu>\UserData\Ovomium.cfg avec le Bloc-notes (jeu fermé) et mettez
  leurs adresses IP : ManualPeers = "100.64.0.2, 100.64.0.3"
  (chacun met celles des autres ; le port UDP utilisé est 47700).
- Le jeu ne démarre plus / plante : lancez « Desinstaller Ovomium », puis dans
  Steam : clic droit sur le jeu → Propriétés → Fichiers installés → Vérifier
  l'intégrité des fichiers.
- Windows bloque l'installeur sans bouton « Exécuter quand même » (Smart App
  Control) : clic droit sur le .zip → Propriétés → cochez « Débloquer » → OK,
  puis extrayez-le à nouveau.
- Envoyez à la personne qui vous a donné le mod :
  * Ovomium-installation.log (dans ce dossier)
  * <dossier du jeu>\MelonLoader\Latest.log


DÉSINSTALLER
------------
Double-cliquez sur « Desinstaller Ovomium ». Le mod est retiré, LMD-Camera aussi
(sauf si vous l'aviez installé vous-même), et MelonLoader si aucun autre mod ne
s'en sert (il vous le demande). Vos réglages restent dans <dossier du jeu>\UserData.


LINUX / STEAM DECK
------------------
Dans un terminal, depuis ce dossier :  bash install-linux.sh
(désinstaller : bash install-linux.sh uninstall). Jeu fermé, sans sudo.
